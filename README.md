# F1 Controller

Turn your Android phone into an authentic Formula steering wheel, pull-down pedals and button box with live telemetry for PC racing games.

## Downloads (latest version)

| File | Platform | What it is |
|---|---|---|
| [**F1Controller-Setup.exe**](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/F1Controller-Setup.exe) | **Windows 10/11** | **All-in-One Setup Wizard** (Installs F1 Controller, ViGEmBus driver & firewall rules) |
| [**F1Controller.apk**](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/F1Controller.apk) | **Android 8+** | **F1 Cockpit Mobile App** (Steering wheel, pedals & live HUD telemetry) |

PlayStation / Xbox consoles are not supported (PC only).
