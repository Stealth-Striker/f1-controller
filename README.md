# F1 Controller

Turn your Android phone into an authentic Formula steering wheel, pull-down pedals and button box with live telemetry for PC racing games.

## Downloads (latest version)

| File | What it is |
|---|---|
| [F1Controller.exe](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/F1Controller.exe) | Windows 10/11 PC app (Companion GUI & System Tray) |
| [F1Controller.apk](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/F1Controller.apk) | Android app (Android 8+) |
| [Quick Start guide](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/F1-Controller-Quick-Start.html) | Setup steps & telemetry guide |
| [How-to-Connect.txt](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/How-to-Connect.txt) | Connect with Wi-Fi, Bluetooth or USB |
| [ViGEmBusSetup_x64.msi](https://github.com/Stealth-Striker/f1-controller/releases/latest/download/ViGEmBusSetup_x64.msi) | Virtual Xbox 360 controller driver for Windows |

PlayStation / Xbox consoles are not supported (PC only).
